# Admin Cheat Sheet

Curated, reference-only snippets for common macOS administration tasks.

> [!WARNING]
> These are **examples to copy and adapt**, not turnkey scripts. Review every
> command before running it, and never paste credentials, internal hostnames,
> domain names, or real account names into committed files.

## Topics

Snippets are grouped by area, for example:

- User context & directory queries
- FileVault & SecureToken
- Active Directory bind / unbind
- Configuration profiles
- Certificates & trust settings
- Jamf, Azure AD & Platform SSO
- `awk` / `sed` quick reference

> [!NOTE]
> Replace all environment-specific values (tenant IDs, domains, usernames,
> hostnames, keychain paths) with placeholders such as `example.com`,
> `<tenant-id>`, or `<username>` before committing.
